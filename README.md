# متابعة المخدومين — نظام موحّد (سيرفر واحد + برنامج كمبيوتر + ويب + موبايل)

دلوقتي فيه **Backend واحد بس** (`server/`)، وكل النسخ عملاء ليه. أي تعديل من أي نسخة بيتخزّن في نفس قاعدة البيانات، وبيظهر في باقي النسخ أول ما تفتح الصفحة أو تعمل تحديث.

```
                    ┌──────────────────────────┐
  برنامج الكمبيوتر ─┤                          │
  (desktop/ Tkinter)│   server/  (FastAPI)     │── قاعدة البيانات (SQLite)
  تطبيق الويب ──────┤   server.py + db.py      │── الصور / النسخ الاحتياطية
  (webapp/ PWA)     │   الصلاحيات والتحقق      │
  تطبيق Flutter ────┤   كلها هنا               │
  (flutter/)        └──────────────────────────┘
```

## الفولدرات

| الفولدر | إيه هو |
|---|---|
| `server/` | **الـ Backend الوحيد**. `db.py` (المنطق وقاعدة البيانات) + `server.py` (الـ API والصلاحيات). ده الملف الوحيد اللي بيتعدّل لما تغيّر أي قاعدة. |
| `desktop/` | برنامج الكمبيوتر (Tkinter). **مفيهوش `db.py`** — فيه `api_client.py` بيكلّم السيرفر. |
| `webapp/` | تطبيق الويب (PWA) — السيرفر نفسه بيقدّمه على `/`. |
| `flutter/` | مشروع تطبيق الموبايل (أندرويد/آيفون). راجع `flutter/README.md`. |
| `tests/` | اختبار شامل (53 فحص) بيشغّل السيرفر + برنامج الكمبيوتر الحقيقي + عميل موبايل. |
| `Dockerfile` | للنشر على استضافة بتدعم Docker. |

## التشغيل محليًا (للتجربة)

```bash
# 1) السيرفر
cd server
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8000
#   → تطبيق الويب على http://localhost:8000  (admin / admin أول مرة)

# 2) برنامج الكمبيوتر (في نافذة تانية)
cd desktop
pip install -r requirements.txt
python main.py
#   → في شاشة الدخول اكتب رابط السيرفر: http://localhost:8000
```

رابط السيرفر بيتحفظ في `~/.mokhdomeen_client.json` فمش هتكتبه تاني.

## النشر الحقيقي (عشان الكل يستخدمه من أي مكان)

لازم السيرفر يتنشر على الإنترنت **بـ https**. متغيّرات البيئة:

| المتغير | معناه |
|---|---|
| `DATA_DIR` | مكان قاعدة البيانات والصور والنسخ الاحتياطية. **لازم يكون على تخزين دائم** (Volume). |
| `ADMIN_INITIAL_PASSWORD` | كلمة مرور الأدمن في **أول تشغيل** (بدل `admin`). **اضبطها قبل أول تشغيل على أي سيرفر منشور.** |
| `APP_TZ` | المنطقة الزمنية (افتراضي: مصر `EET-2EEST,M4.5.5/0,M10.5.4/24`). |
| `PORT` | البورت (الاستضافات بتحدده). |

### ⚠️ التخزين الدائم — أهم نقطة

قاعدة البيانات ملف على قرص السيرفر. الاستضافات المجانية زي Render's free tier **بتمسح الملفات** مع كل إعادة نشر أو سكون طويل — يعني **تفقد كل البيانات**. لازم استضافة فيها Volume دائم. مثال على Fly.io:

```bash
fly launch                                  # هيكتشف الـ Dockerfile
fly volumes create mokhdomeen_data --size 1
fly secrets set ADMIN_INITIAL_PASSWORD='كلمة-مرور-قوية'
```
وفي `fly.toml`:
```toml
[mounts]
  source = "mokhdomeen_data"
  destination = "/data"
```
ثم `fly deploy`. السيرفر بيعمل **نسخة احتياطية تلقائية كل يوم** (بيحتفظ بآخر 30) في `DATA_DIR/backups`، لكن النسخ دي على نفس القرص — نزّل نسخة منها دوريًا لمكان تاني (صفحة المستخدمين → نسخ احتياطي).

> `Dockerfile` ما اتجرّبش فعليًا (مفيش Docker عندي). هو بسيط، لكن لو فشل البناء ابعتلي رسالة الخطأ.

## نقل بياناتك القديمة من برنامج الكمبيوتر القديم

شكل قاعدة البيانات نفسه، فالنقل بسيط:
1. أوقف السيرفر (لو شغّال).
2. انسخ `mokhdomeen.db` القديم **وفولدر `photos/`** إلى `DATA_DIR` على السيرفر.
3. شغّل السيرفر — بيرقّي القاعدة تلقائيًا وبيصلّح مسارات الصور.

## إيه اللي اتغيّر في سلوك برنامج الكمبيوتر

- **محتاج إنترنت وسيرفر شغّال** عشان يفتح (مفيش قاعدة بيانات محلية تاني).
- أبطأ شوية من الأول لأن كل عملية رحلة للسيرفر. الواجهة بتتجمّد لحظات وقت الاتصال، وأطول لو الاستضافة المجانية نايمة وبتصحى (ممكن دقيقة أول مرة).
- القواعد موحّدة لكل النسخ: الاسم والفصل بدون أرقام، الهاتف مصري صحيح، "يحتاج افتقاد" = غاب مرتين من آخر 3 جلسات (ثابتة على السيرفر).
- النسخ الاحتياطي بقى على السيرفر (يومي تلقائي + يدوي)، مش عند إغلاق البرنامج.
- **"الحيّة" معناها بيانات مشتركة**: تعديل حد تاني بيظهر لما تفتح الصفحة أو تغيّر التبويب — مش إشعار لحظي تلقائي (مفيش push).

## الأمان

- **الصلاحيات (مرحلة/فصل) متفرضة على السيرفر نفسه** لكل العمليات (عرض، تعديل، حذف، حضور، صور، تصدير)، مش بس في شكل الواجهة. أي عميل (حتى لو اتعدّل) مش هيقدر يتخطاها. متجرّب في الاختبار الشامل.
- الجلسات (Tokens) 12 ساعة، وبتتلغى لما المستخدم يتحذف أو تتغيّر صلاحياته أو كلمة مروره. بتتخزّن في الذاكرة، فإعادة تشغيل السيرفر = الكل يسجّل دخول من جديد.
- قفل الحساب 5 دقايق بعد 5 محاولات دخول غلط.
- مفيش تشفير للاتصال من تلقاء نفسه: **استخدم https دايمًا**.
- بيانات أطفال (أسماء وتليفونات وتواريخ ميلاد): راجع قوانين الخصوصية عندكم، وخلي كلمات المرور قوية.
- مفيش تحقق بخطوتين، ومفيش حد أقصى لمحاولات الدخول على مستوى الـ IP (بس على مستوى المستخدم).
- السيرفر مصمم لنسخة واحدة تشتغل (SQLite) — متشغّلوش على أكتر من instance.

## حدود صريحة (اللي ما اتجرّبش)

- **Flutter والـ Codemagic والـ Dockerfile**: مكتوبين بعناية لكن ما اتشغّلوش فعليًا (بيئتي مفيهاش Flutter/Android/Xcode/Docker). جرّبهم وابعتلي أي خطأ.
- برنامج الكمبيوتر اتجرّب على لينكس (Xvfb). ملف `.exe` بتاع ويندوز لازم تبنيه على ويندوز: `pyinstaller --onefile --windowed main.py`.
- مجلد `mokhdomeen_app` القديم (برنامج الكمبيوتر المستقل بقاعدة محلية) لسه موجود كنسخة **قديمة تعمل بدون إنترنت** — بس بياناته منفصلة تمامًا ومش هتتزامن مع السيرفر. استخدم `desktop/` بدله.

## مرجع سريع للـ API

كل الطلبات (غير تسجيل الدخول) بتحتاج `Authorization: Bearer <token>`.

| المجال | المسارات |
|---|---|
| الدخول | `POST /api/login` · `POST /api/logout` |
| المراحل والفصول | `GET/POST /api/stages` · `PUT/DELETE /api/stages/{id}` · `GET /api/classes` |
| المخدومون | `GET/POST /api/students` · `GET/PUT/DELETE /api/students/{id}` · `.../restore` · `.../permanent` · `.../attendance_history` · `.../photo` · `GET /api/students/deleted` · `POST /api/students/import_excel` |
| الحضور | `GET /api/attendance/today` · `GET /api/attendance/map` · `POST /api/attendance` · `GET /api/absentees` · `GET /api/stats` |
| أخرى | `/api/birthdays` · `/api/dashboard` · `/api/verses` · `/api/verse-of-day` · `/api/lessons` · `/api/families` |
| تصدير | `/api/export/attendance_report` · `phone_list` · `stats_pdf` · `lessons_pdf` |
| أدمن | `/api/users` · `/api/activity_log` · `/api/backup` · `/api/backups` · `/api/backup/restore` |

قيم المرحلة في الـ query: فاضي = الكل، `unset` = بدون مرحلة، أو رقم المرحلة. قيم الحضور بترجع `true/false` حقيقية.
